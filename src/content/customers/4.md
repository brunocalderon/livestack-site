## Monitors as code at Selvo

**Coverage that drifted**

Selvo's infrastructure grows every week. When monitors were created by hand, coverage depended on who remembered to add them. Some services launched without checks. Others were retired, but their monitors kept sending alerts for months.

**One source of truth**

The infrastructure team moved every monitor into Terraform with the Navy provider. A service module now includes its HTTP monitors, alert routing and status page component. Reviewers see monitoring changes in the same pull request as the code, and nothing reaches production without a check.

**Heartbeats for scheduled work**

Selvo also runs thousands of scheduled jobs for maintenance and data replication. Each one now pings a Navy cron heartbeat when it finishes. If a job does not report in on time, the owning team gets an alert before the delay affects customers.
