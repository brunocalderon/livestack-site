Navy now confirms every outage from **three regions** before anyone gets alerted. When a check fails, Navy immediately re-runs it from other regions on different networks. An incident opens only when three regions agree, so a flaky route or a single bad network no longer pages your team.

**Key Highlights:**

- **Three-region confirmation:** Outages and recoveries are both confirmed from three regions, on every monitor and every plan.
- **Six new regions:** Checks now run from 18 regions, including new locations in South America, Africa and Southeast Asia.
- **Regional failures:** Failures seen in only one region are recorded on the monitor and in the response time chart without paging anyone.
- **Region selection:** Choose which regions run each monitor, or keep the default of all 18.

This release makes every alert one you can trust. Confirmation is on by default and needs no setup.
