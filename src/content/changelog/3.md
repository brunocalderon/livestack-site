You can now manage Navy entirely as code. The new **Terraform provider** covers monitors, alert policies, escalation policies, on-call schedules and status pages. The **Navy CLI** applies the same configuration from YAML files, so teams that do not use Terraform get the same workflow.

**Key Highlights:**

- **Terraform provider:** Every Navy resource is available in HCL, with full plan and apply support.
- **Navy CLI:** Validate, diff and apply YAML config from your terminal or from CI.
- **Import existing monitors:** Export the monitors you created in the dashboard to Terraform or YAML in one command.
- **REST API parity:** The provider and CLI use the public REST API, so anything in the dashboard can be scripted.

This release puts monitoring in the same pull request as the service it watches. The provider and CLI are available on every plan.
