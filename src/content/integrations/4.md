## About the Branvo integration

Most outages start with a change. The Branvo integration draws each deploy on your Navy charts, so you can see at a glance whether a slowdown started with a release, and it opens an issue on the right repository when an incident is confirmed.

## Key features

- **Deploy markers:** Every release shows up on the response time and uptime charts.
- **Issues from incidents:** Open an issue with the timeline and the failing checks.
- **Pull request checks:** Run your monitors against preview deploys before you merge.
- **Linked postmortems:** Link the issue to the postmortem when you close the incident.

## Get started

In Navy, open Settings, then Integrations, and choose Branvo. Install the Navy app on the repositories you deploy from and pick which events to follow.
