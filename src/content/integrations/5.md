## About the Tervani integration

Tervani lets you keep Navy in the same files as your servers and databases. Every monitor is declared next to the service it watches, changes go through review, and nobody edits a check by hand at two in the morning.

## Key features

- **Every resource:** Monitors, alert rules, escalation policies and status pages.
- **Plan before apply:** See exactly what will change before it changes.
- **Import existing monitors:** Bring monitors created in the dashboard into your files.
- **Drift alerts:** Know when someone changes a monitor outside of Tervani.

## Get started

Create an API key in Navy under Settings, then API. Add the Navy provider to your Tervani project, set the key and run your first plan.
